# Composition Brief: Cascade

## Purpose
Create a 20-second 1920×1080 launch trailer from real Cascade browser captures. The trailer should feel like a municipal emergency-control interface becoming a strategy-game trailer, not a generic SaaS promo.

## Required project material
Use the four deterministic captures created by npm run launch:capture:
- verification/public-launch/cascade-menu.png
- verification/public-launch/cascade-live-city.png
- verification/public-launch/cascade-decision.png
- verification/public-launch/cascade-training.png

Do not invent UI screenshots. Do not show future hidden threat information.

## Palette
- Background: #061018
- Primary text: #eaf4f2
- Restored control: #6bd9bd
- System cyan: #6cc4d1
- Risk: #ff815c
- Supporting muted text: #8da8ad

## Motion
- Slow 2–4% camera push on product shots.
- Dark gradient overlays only where required for text readability.
- Crossfades between wide UI scenes; one harder cut into the intervention scene.
- No excessive shake, glitch, chromatic aberration, or generic HUD decoration.
- Text enters quickly, then holds long enough to read.

## Audio
Generate an original procedural electronic bed locally. It should be dark and restrained, with low pulses and a few transition hits. No third-party track is required.

## Accessibility / readability
Text should remain high contrast against the composited background. Never put important copy directly on bright orange UI without a dark backing gradient.

## Output
- brag-output/brag.mp4
- brag-output/brag.jpg
- brag-output/share-copy.txt

The strongest poster frame is the final Cascade title card after all text has settled.
