# Local /brag composition

The canonical `/brag` creative plan lives one level up.

This project follows `/brag`'s inspect → storyboard → composition → render structure. Hyperframes is not installed in the autonomous execution environment, so the checked-in fallback renderer uses FFmpeg while preserving `/brag`'s real-product, readable-text, poster-frame, and share-copy requirements.

The renderer consumes only real Cascade screenshots produced by `npm run launch:capture`. No mock product UI is substituted.
